# 本地 MCP：配置、信任和工具生命周期

Weave 支持本机 stdio MCP Tools，并把它们接入现有 Plugin Kernel、Tool Pipeline、
工具审批和 Session 事件链路。Studio 的“插件”面板同时管理本地 ESM 插件和 MCP
服务；浏览器通过 Server HTTP 接口管理，不能直接启动进程或读取环境变量。

## 在 Studio 添加服务

1. 启动 `pnpm dev`，或使用 `pnpm desktop:dev` 启动桌面开发环境。
2. 在右侧“添加面板”中打开“插件”，添加本地 MCP 服务。
3. 填写稳定 ID、显示名称、可执行文件绝对路径、固定工作目录和参数 JSON 数组。
   路径属于运行 Weave Server 的电脑。参数按数组原样传递，不经过 Shell；
   `""`、空格、反斜线和参数顺序都具有实际意义。
4. 如需凭据，只添加“目标变量 → 宿主变量引用”的映射。先在启动 Weave 的环境
   中设置宿主变量，表单只填写变量名。
5. 保存配置。新配置先处于未信任状态，保存和取消审阅都不会启动这个服务。
6. 打开“审阅并信任”，检查 Server 规范化后的完整命令、参数、目录、环境引用
   和摘要，确认后信任并启用。连接初始化及工具发现成功后，面板展示实际工具。

配置的 JSON 形式如下；路径需替换为本机真实路径：

```json
{
  "schemaVersion": 1,
  "id": "local-example",
  "label": "Local example",
  "transport": "stdio",
  "command": "/absolute/path/to/node",
  "args": ["/absolute/path/to/mcp-server.mjs", "--mode", "local"],
  "cwd": "/absolute/path/to/workspace",
  "env": {
    "SERVICE_TOKEN": { "fromHostEnv": "MY_SERVICE_TOKEN" }
  }
}
```

Server 最多保存 8 个有效配置，每个最多 64 项参数、32 项显式环境映射。ID 使用
小写字母、数字和中间连字符，最长 24 字符。Windows 会规范化环境变量名；
`WEAVE_` 前缀不可用于目标或引用。启动器必须是可执行文件，Windows 不接受
`.cmd`/`.bat` 作为启动命令。Weave 当前不负责下载或安装第三方程序。

## 两种信任边界

MCP 信任绑定规范启动配置：命令、字面参数、工作目录、显式环境引用和策略版本。
显示名称不影响启动信任。修改启动字段会清除有效信任并停用，之后必须重新审阅；
恢复到旧配置也不会自动恢复信任。审阅会展示上次审阅配置与当前配置的字段差异。

配置摘要不能证明可执行文件、脚本和依赖内容没有变化。被启动的 MCP 进程使用
当前系统用户的普通进程权限；工具审批不会把已经运行的服务变成沙箱。SDK 还会
继承固定的系统环境白名单，因此空的显式映射不代表子进程环境为空。
显式环境值在每次新建连接时解析一次，不存入信任事件；轮换值后显式重载即可。

工具发现发生在启动以后。服务提供的描述、Schema 和注解都是第三方数据，
`readOnlyHint` 等注解不会降低 Weave 的审批等级。所有 MCP 工具都声明高风险
`mcp.call_tool`，并经过共享参数验证、权限策略、审批、取消、超时和结果大小限制。
常规/信任模式仍按现有高风险策略确认每次调用；YOLO 使用其既有策略。
MCP `isError` 会成为可恢复的失败工具结果，模型可以修正参数后继续。

## 刷新、重载和回合

打开或重新激活插件面板只通过 GET 重新读取目录状态，不创建新连接。明确点击重载才会重建 ESM 和 MCP 的
完整 Generation，并为仍启用的 MCP 服务创建新连接。当前回合固定使用原代，
下一回合使用新代；旧连接在最后一个引用它的回合结束后释放。

| 操作     | 持久配置与信任               | 回合与连接                     |
| -------- | ---------------------------- | ------------------------------ |
| 停用     | 保留当前摘要的信任           | 新回合不再使用，旧回合可以排空 |
| 启用     | 要求当前摘要仍被信任         | 构建新代并重新连接             |
| 撤销信任 | 清除信任并停用               | 再次使用前必须审阅             |
| 移除     | 删除有效配置，保留追加式历史 | 被旧回合引用的记录显示为排空中 |
| 显式重载 | 不改变信任决定               | 创建全新连接和冻结工具目录     |

停用、撤销和移除默认在下一回合生效，也可以选择立即生效。
**立即生效会取消所有当前及退役代的进行中回合**，包含其他会话，并非只取消
对所选服务的调用。即使当前界面看不到运行会话，此选项也始终可用。

配置和信任存入 Server 数据库的追加式事件，重启后恢复有效决定；已信任且启用
的配置会重新连接。桌面端数据库位于该 Electron 实例的 `userData` 目录。
停止 Server 会先取消和排空回合、释放连接，再关闭持久库。

## 状态和故障排查

面板分别显示持久决定序号、重建是否成功、当前 Generation、连接健康、目录过期
和旧代排空状态。“决定已保存但重建未完成”表示持久写入成功，需要检查错误后
显式重载。不会根据旧注册表里仍有工具就把失败连接显示成健康。

- **未信任/配置变化**：重新打开审阅，确认完整规范配置。
- **环境引用缺失**：在启动 Weave 的宿主环境中设置引用变量后重载。Studio 不读取值。
- **工具目录过期（stale）**：服务通知工具目录变化。当前目录保持冻结，显式重载
  才会发现新目录；不会自动重连或重放工具调用。
- **连接失败/退出**：检查命令、工作目录、程序依赖和 stdio 协议。协议输出只能
  写到 stdout；诊断日志写 stderr。失败服务单独隔离。
- **配置冲突（409）**：其他操作改变了配置或授权。界面会重新读取状态，并使当前
  表单/审阅失效；关闭后重新打开，确认后再提交，不会自动替换序号重试。
- **目录暂未同步**：两个控制面读到不同 Generation 或请求失败。界面保留最后一致
  的目录并禁用管理写入，刷新恢复后继续。
- **资源不足/关闭失败**：所有当前、候选和排空连接共享 32 个连接的保守上限。
  关闭失败不会释放该配额；排查进程后重启宿主，不能靠反复重载绕过。

当前范围是本地 stdio Tools。远程 MCP、Resources/Prompts 接入、自动安装、市场、
操作系统沙箱和 Crew 编排仍是独立后续工作。架构依据见
[ADR 0004](../adr/0004-mcp-stdio-tools.md) 和
[MCP 设计](../superpowers/specs/2026-11-21-mcp-stdio-design.md)。

# Weave Coding Skills

A maintained example of a declarative Weave package. It contains instructions
and text references, has no executable entry, and requires no build step.

The two Skills help review a proposed change and verify its behavior using tools
already available in the current workspace. They do not install tools, grant
permissions or authorize commits, pushes, publication or messages to others.

Use Studio's plugin marketplace local import workflow with this directory. Review
the exact manifest and digest, import an inert candidate, and separately activate
the version. In a Session, choose `review-change` or `verify-change` from the Skills
picker. The same names from other sources remain separate qualified references.

The package is authored for Weave. It is an example in this repository, not an
already published marketplace release. Fixed GitHub publication must reference
an actual merged commit and the exact example subdirectory. See the repository's
declarative-package and marketplace-publishing guides for the current workflow.

# 信任、工具与 Generation

## 两种决定

启动信任绑定 command、字面 args、cwd、显式 env 引用和 policyVersion 的规范摘要。
它不证明二进制/脚本/依赖内容不变，也不把普通同用户进程变成沙箱。服务启动后才有
工具发现，描述、schema 和 annotations 都是第三方输入。readOnlyHint 不降低审批。

所有 MCP 工具都是高风险 mcp.call_tool，通过共享 Tool Pipeline 执行：参数校验、策略、
审批、取消/超时和结果大小限制。常规/信任模式按既有高风险策略确认调用，YOLO 保持
其既有策略；不要以官方名或第三方只读注解建议绕过。MCP isError 变为可恢复失败
工具结果，模型可修正输入；不因此自动重启服务或重放调用。

## 操作与版本

打开/重新激活管理页仅 GET 状态，不创建连接。显式全量重载构建完整 ESM+MCP
Generation，仍启用服务创建新连接。当前回合固定旧代，下一回合用新代；旧连接在最后
引用回合结束后释放。stale 表示服务通知工具目录变化，当前目录保持冻结，需显式
重载才能发现新目录，不自动重连或重放。

| 操作     | 持久事实                   | 回合效果                 |
| -------- | -------------------------- | ------------------------ |
| 停用     | 保留当前摘要信任           | 新回合不用，旧回合可排空 |
| 启用     | 需要当前摘要仍可信         | 构建新代并连接           |
| 撤销信任 | 清除信任并停用             | 再次使用需审阅           |
| 移除     | 删除有效配置，保留追加历史 | 旧回合仍引用时显示排空   |
| 重载     | 不改变信任决定             | 新连接和新冻结目录       |

停用/撤销/移除默认下一回合；立即生效会取消所有当前及退役代进行中的回合，包含
其他 Session。用户需要理解范围，模型不擅自选择或执行。配置/信任恢复自数据库，
宿主重启时可信且启用服务会重连；退出先取消排空并释放连接，再关闭持久库。

“决定已保存但重建未完成”不是全部失败也不是全部成功。报告保存的 decisionSequence、
applied/error 和 generation/health；旧工具仍存在不能证明新连接健康。先排查错误，
再由用户在管理页显式重载。模型不通过 HTTP、数据库或 shell 重新制造授权事实。

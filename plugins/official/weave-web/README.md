# Weave 联网

`weave-web` 提供 `web_search`（搜索）和 `web_fetch`（网页读取）。在插件市场安装，或在“已安装”导入此包后，审阅 manifest、目录摘要及 `network:request` 声明，再独立激活。普通导入不会启用工具；激活、停用与撤销信任通常从下一回合生效，正在执行的回合保留其插件版本和配置。

## 网页读取

`web_fetch` 无需密钥。它只读取公开的 HTTPS 443 文本页面，返回来源 URL、读取时间与有界正文。支持 HTML、纯文本、Markdown 和 JSON 的 UTF-8 内容；不执行脚本或读取图片、PDF、下载附件。页面正文是外部不可信资料；回答时应引用实际使用的来源链接。

调用参数为 `url`，可选 `maxChars`（256–8000，默认 6000）。只自动跟随同一 origin 最多三次跳转；跨站跳转需要新的工具调用与审批。内网、localhost、HTTP、非 443 端口及保留地址均不支持。DNS 全答案检查与定向连接属于本插件的访问限制，不是进程网络沙箱。

## 搜索配置

搜索使用单独的 Tavily 账户密钥，由启动 Weave 宿主的操作者配置这两个环境变量：

```dotenv
WEAVE_WEB_SEARCH_PROVIDER=tavily
WEAVE_WEB_TAVILY_API_KEY=replace-with-your-own-tavily-key
```

只发送明确的 `query`，不自动附加会话、项目、文件或模型设置。可选 `maxResults` 为 1–5，默认 5。使用 Tavily basic 搜索，不自动生成答案、抓取结果页或切换供应商；账户费用与额度由自己的 Tavily 计划决定。未配置搜索时仍可读取网页。

Server 开发命令 `pnpm dev` 由 Server 的 `--env-file-if-exists=../../.env` 加载仓库根 `.env`。正式桌面应用继承启动进程环境，不自动读取项目 `.env`；需要在启动应用前设置环境并重新启动宿主。配置在插件实例加载时冻结，修改文件或外部环境不会改变已运行实例；宿主启动环境变化后重启。不要把真实密钥放在对话、工具参数、插件文件或 Git 中。

## 审批与结果

两个工具都声明只读并显式请求联网审批。`ask` 与 `trust` 模式在 DNS/HTTP 之前展示查询或完整 URL；拒绝、取消和审批过期不发送请求。`yolo` 沿用宿主的审批规则，策略插件仍可收紧为确认或拒绝。插件安装信任与每次调用审批是两件独立的事。

单次联网有 20 秒总时限；原始响应最多 512 KiB，解压文本最多 1 MiB，完整工具结果最多 12 KiB。正文超过显示预算时明确标记 `truncated`；来源 URL 保持完整，不把截断链接当成引用。搜索来源在该次调用内编号 `S1` 等，跨调用应使用完整 URL 和工具调用上下文区分。结果在现有会话日志中保存，刷新后可读取原结果；没有自动缓存、后台爬取或重试。

密钥只用于固定 `https://api.tavily.com/search` 的 Bearer header，不用于页面请求。插件对自己持有的密钥做限定的文本脱敏和来源筛除，不提供对用户任意输入秘密的全局识别保证。搜索失败会给出配置、鉴权、额度、限流或网络错误，不伪装为空搜索成功。

## 维护与验证

此目录是单 ESM 可安装产物。维护源码位于相邻 `weave-web-source/`，使用现有 Weave Plugin CLI 进行严格 TypeScript 检查并生成 `index.mjs`。从实际 Weave checkout 根目录运行：

```sh
pnpm web-plugin:verify
```

该命令重建并逐文件比较已提交产物，验证真实导入、独立激活、SQLite 重启与停用生命周期。测试不需要 Tavily 密钥。确定性 HTTP adapter 验证接口契约，不能证明当前 Tavily 账户、计划或公网服务可用；未经实际请求不声称完成供应商活网验收。

本插件以可信 Node ESM 在宿主进程运行，具有相同 OS 用户的进程权限。`network:request` 用于权限审阅展示，不限制恶意插件直接使用 Node API；不要将它理解为 OS、容器或浏览器沙箱。
